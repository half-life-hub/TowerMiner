# Tower Miner Asset Prompts

Use these prompts to generate cohesive visual assets for `Tower Miner`.

## Global Style Direction

Use this style block with every asset prompt:

```text
Stylized mobile game art for Tower Miner, semi-pixel inspired but polished, dark underground fantasy mining theme, chunky readable shapes, crisp edges, subtle bevels, soft bloom, high contrast, modern iOS game quality, no text, no watermark, no photorealism, no busy background.
```

Recommended source size:

- App icon: `1024x1024`
- Tile sprites: `512x512`
- UI icons: `512x512`
- Particles/effects: transparent PNG if available
- Backgrounds: `1536x2048` portrait

---

No text, no logo letters, no transparent background, no rounded corners baked into the art.

## Prompt Notes

- Keep assets readable at small phone sizes.
- Prefer one strong focal object per image.
- Avoid noisy details that disappear inside the tile grid.
- Ask for transparent backgrounds for sprites and icons.
- Ask for no baked rounded corners for app icons.
- Keep all assets in the same lighting direction: top-left key light with soft cyan glow accents.
